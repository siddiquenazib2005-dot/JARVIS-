# AURIX AI Companion Roadmap

AURIX is an original red/black futuristic Android AI companion inspired by the user's reference style. Target: voice assistant + chat + phone control + screen automation + missions.

## P0 Build
- Restore real Gradle wrapper.
- Build `:app:assembleDebug`.
- Fix compile errors.

## P1 Premium UI
- Red/black neon theme.
- AURIX name/branding.
- Home hero with animated orb.
- Feature dashboard: Communication, Calls, Media, Device, Files, Screen Automation, Missions, Search & Apps.

## P2 Working Core
- API key settings.
- Chat streaming.
- TTS/STT.
- Accessibility permission onboarding.

## P3 Automation
- Open app, tap, type, scroll, back/home.
- WhatsApp/SMS/call flows with confirmation.
- Screen read via Accessibility + OCR fallback.

## P4 Advanced
- Notifications, maps/location, storage analyzer, PC connect, mission pause/resume.
